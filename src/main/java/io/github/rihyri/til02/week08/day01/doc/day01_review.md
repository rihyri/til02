# Week 08 - Day 01. 학습 회고

<br>

이번 수업에서는 Spring AOP(관점 지향 프로그래밍)의 필요성과 기본 개념을 학습했다. 로깅, 예외 기록, 실행 시간 측정처럼 여러 곳에 반복되는 횡단 관심사를 비즈니스 로직에서 분리하는 방법을 살펴보았다.

Aspect, Advice, JoinPoint, Pointcut의 역할을 배우고, `execution()`, `within()`, `@annotation`을 사용하여 AOP 적용 대상을 선택했다. 또한 `@Before`, `@AfterThrowing`, `@Around`로 각각 다른 시점에 공통 기능을 수행하는 방법을 실습했다.

<br>

개념을 읽을 때는 이해한 것 같았지만, 예시 코드를 보면서 **JoinPoint와 Pointcut의 역할**을 구별하기 어려웠다. 여러 Advice가 하나의 메서드에 적용되면 어떤 코드가 실행되고 어떤 로그가 출력되는지도 처음에는 헷갈렸다.

특히 `ProceedingJoinPoint`와 `proceed()`가 기존 서비스 메서드의 실행과 어떻게 연결되는지 이해하는 데 시간이 필요했다.

<br>

예시 코드를 작성하며 상품 조회 API를 대상으로 AOP를 적용해 보면서 서비스의 핵심 로직을 수정하지 않고도 공통 로직 기능을 추가할 수 있다는 것을 확인했다.

- `JoinPoint` : 현재 실행되는 메서드의 이름과 인자 등의 정보를 제공한다.
- `Pointcut` : Advice를 적용할 메서드를 고르는 조건이다.
- `@annotation()` : 선택한 메서드에만 공통 기능을 적용할 수 있다.
- `@AfterThrowing` : 서비스에서 예외가 전파될 때 기록을 남긴다.
- `@Around` : `proceed()`를 통해 실제 메서드 실행을 진행하면서 전후 동작을 제어한다.

<br>

이번 수업에서는 어노테이션을 단순히 외우는 것보다 **프록시가 메서드 호출을 가로채고 Pointcut 조건에 따라 Advice를 실행하는 흐름**을 이해하는 것이 더 중요하다고 느꼈다.
